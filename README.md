# ☕ NORÉ COFFEE

**Seu momento merece ser extraordinário.**

A NORÉ COFFEE é um projeto de desenvolvimento web inspirado no conceito de uma cafeteria premium. A proposta é proporcionar uma experiência visual elegante e sofisticada, valorizando a identidade da marca e a apresentação de seus produtos.

## ✨ Sobre o projeto

O projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento front-end, utilizando HTML e CSS para construir uma landing page com identidade visual própria.

A inspiração vem de cafeterias contemporâneas, com uma estética minimalista, combinando tons escuros e detalhes dourados para transmitir exclusividade e sofisticação.

## 🎨 Identidade visual

A identidade da NORÉ COFFEE foi pensada para transmitir elegância em cada detalhe.

- **Preto (`#010103`):** sofisticação e modernidade.
- **Dourado (`#D3AD7F`):** exclusividade e requinte.
- **Branco (`#FFFFFF`):** contraste e legibilidade.

## 🚀 Funcionalidades e seções

O site está organizado em diferentes seções:

- **Home:** apresentação da cafeteria e mensagem principal.
- **Sobre:** apresentação do conceito da marca.
- **Menu:** exposição dos produtos e preços.
- **Avaliações:** espaço dedicado à experiência dos clientes.
- **Endereço:** seção de localização.
- **Rodapé:** informações complementares e redes sociais.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização, layouts, Flexbox e Grid.
- Google Fonts — tipografia do projeto.
